EXERCÍCIO 01 - Exercício 1 — Função ou procedimento?

Str() - FUNÇÃO
O Str é uma função porque retorna um valor (string) para o programa (fazendo a conversão de número -> string)

QOut() - PROCEDIMENTO
QOut() é um procedimento porque não retorna nenhum valor "útil" para o programa, ele apenas uma informação na tela para o usuário.

Date() - FUNÇÃO
Date() é uma função porque retorna a data atual para o programa, permitindo que ela seja armazenada ou utilizada em outros contextos.

Len() - FUNÇÃO
Len() é uma função porque retorna o do tamanho de uma string/array para o programa.

Upper() - FUNÇÃO
Upper() é uma função porque ele converte e retorna a string selecionada com letras maiúsculas para o programa.

ClearScreen() - PROCEDIMENTO
ClearScreen() é um procedimento porque ele não retorna um "valor" e sim é chamado para limpar a tela para o usuário.

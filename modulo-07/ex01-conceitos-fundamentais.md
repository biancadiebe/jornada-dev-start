EXERCÍCIO 1 - CONCEITOS FUNDAMENTAIS

a. Qual é a função do AppServer?
Funciona como o "cérebro", é ele quem processa o código e conversa com o banco de dados para processar as informações.

b. O que é o RPO?
Quando usamos o Harbour e compilamos o arquivo em .prg, ele gera o .exe (executável). No Protheus, ele é compilado para um repositório chamado RPO onde ficam armazenados todas essas rotinas do sistema.

c. Para que serve o Configurador (SIGACFG)?
Ele permite controlar quem consegue ver e editar cada campo, por usuário ou grupo sem precisar programar. 

d. Qual a diferença entre o campo Real e o campo Virtual no SX3?
O campo real é gravado de forma "física" no banco de dados, e o virtual existe apenas no dicionário de dados, não é gravado no banco e é calculado apenas na execução do sistema, apenas para exibição ou processamento de dados.
